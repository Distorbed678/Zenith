- Verified by suites: `block-facts` (ZBF1; every column below is compared for every state of the block).
- Sources: local reference reading of the 26.3 client (2026-11-25, reader session; the registration of every block and
  its class); data-generator `reports/blocks.json` for the registry order and state counts. Generated by the reader
  from those readings into this own-format table; it contains facts only (no code, no data files).
- Related specs: [`state-facts.md`](state-facts.md) (meaning of every column and flag, defaults, class rules),
  [`shapes-catalogue.md`](shapes-catalogue.md) (the `shape` families), [`shapes.md`](shapes.md),
  [`sound-types.md`](sound-types.md).

## Summary

One row per block, in registry (protocol id) order, 1286 rows. Columns:

- `#` — registry index (0-based protocol id). `id` — the block id without `minecraft:`. `states` — number of states.
- `class` — the game class that supplies the block's behaviour (its public simple name; for copper families the
  *waxed* variants use the plain class and the unwaxed ones the corresponding `WeatheringCopper…` / `Weathering…`
  class with identical shapes; random-tick rules for those are in state-facts §2.10).
- `shape` — the shape family key of `shapes-catalogue.md`.
- `map colour` — the map colour name (state-facts §4); a parenthesised rule gives a per-state variation.
- `hardness / resistance` — destroy time and explosion resistance (single precision; `-1` = unbreakable).
- `sound` — sound type name (`sound-types.md`). `instrument` — note-block instrument.
- `light` — light emission (constant or per-state rule, state-facts §3.3).
- `flags` — only non-defaults: `nc` no collision (and cannot occlude); `no` cannot occlude; `rt` random ticks (the
  property; class rules may override, state-facts §2.10); `tool` requires the correct tool; `lava` ignited by lava;
  `repl` replaceable; `liq` legacy liquid; `air` air; `solid+` / `solid-` force legacy solid on / off; `dyn` dynamic
  shape; `noparticles` no terrain particles; `cond:never|always` redstone conductor predicate; `suff:never|always|
  shulker|piston` suffocation predicate; `view:plane|snow8` view-blocking predicate; `pp:self|above` post-process
  position; `emis:always|sensor-active` emissive rendering; `off:xz|xyz` offset type; `fr=` friction, `spd=` speed
  factor, `jmp=` jump factor, `bnc=` bounce restitution, `fdr=` fall-distance reduction; `push:` push reaction when not
  PUSH_PULL.
